# دليل تعديل الموقع

## الملفات الأساسية
- `index.html`: النصوص، العناوين، الأقسام، بطاقات المشاريع، بيانات التواصل والخبرات والتعليم.
- `css/portfolio.css`: الألوان والتصميم والمسافات والخطوط والتجاوب. لم يتم تغيير ألوان التصميم الأصلية.
- `js/script.js`: قائمة الجوال، الوضع الداكن، تصفية المشاريع، وروابط عرض المواقع.
- `images/`: الصور الشخصية وصور المشاريع والشهادات.
- `files/Yasmin_CV.pdf`: ملف السيرة الذاتية.
- `docs/`: حالة الإنجاز ودليل التعديل.

## تعديل بياناتك
افتحي `index.html` وابحثي عن النص الحالي ثم استبدليه بالنص الجديد. حافظي على أسماء `class` و`id` حتى لا يتأثر التنسيق أو التنقل.

## تعديل مشروع
ابحثي عن عنوان المشروع داخل قسم `id="projects"`، ثم عدّلي:
1. اسم المشروع داخل `h3`.
2. الوصف داخل `p`.
3. التقنيات داخل `project-tech`.
4. الحالة داخل `data-status` والنص داخل `status-pill`.

الحالات المدعومة:
- `completed` للمشروع المكتمل.
- `progress` للمشروع قيد التطوير.
- `planned` للمشروع المخطط.

عند إضافة أو حذف مشروع، حدّثي أرقام أزرار التصفية في بداية قسم المشاريع.

## تغيير صورة
ضعي الصورة الجديدة داخل مجلد `images`، ثم غيّري قيمة `src` للصورة في بطاقة المشروع. استخدمي اسم ملف بسيطًا باللغة الإنجليزية.

## إضافة رابط عرض مشروع
افتحي `js/script.js` وابحثي عن `projectDemoLinks`. أضيفي الرابط الحقيقي بجانب عنوان المشروع المطابق تمامًا. اتركي القيمة فارغة إذا لم يكن هناك موقع منشور.

## تغيير الألوان
افتحي بداية `css/portfolio.css` وابحثي عن `:root`. متغيرات الألوان الأساسية موجودة هناك. لا تغيّريها إذا كنتِ تريدين الحفاظ على الهوية الحالية.

## التشغيل
يمكن فتح `index.html` مباشرة، أو تشغيل المجلد باستخدام إضافة Live Server في VS Code.
