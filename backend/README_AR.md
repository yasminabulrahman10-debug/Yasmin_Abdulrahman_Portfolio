# Backend — واجهة برمجية لمعرض أعمال ياسمين

هذه بداية منظمة للـBackend، وليست النسخة النهائية المتصلة بقاعدة البيانات.

## المتطلبات
- Node.js إصدار LTS حديث
- MySQL Server
- VS Code

## التشغيل
1. افتحي Terminal داخل مجلد `backend`.
2. نفذي:

   ```bash
   npm install
   ```

3. انسخي `.env.example` إلى ملف جديد اسمه `.env`.
4. عدّلي بيانات MySQL داخل `.env`.
5. شغّلي الخادم:

   ```bash
   npm run dev
   ```

6. افتحي هذا العنوان لاختبار الخادم:

   `http://localhost:5000/api/health`

يجب أن يظهر رد JSON يؤكد أن API يعمل.

## تنبيه
اتصال قاعدة البيانات والجداول وتسجيل دخول المديرة وواجهات إدارة المحتوى لم تُبنَ بعد. سنضيفها بالتدريج ونختبر كل مرحلة قبل الانتقال.
